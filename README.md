# OhDupe

A simple Minecraft Java Edition mod for duplicating the item you're holding using a command.

## Features

- **Command-Based:** No GUI or menus.
- **Simple Usage:** Duplicate items directly through chat.
- **Custom Amount:** Specify how many items you want.

## Command

```text
/dupe <amount>
```

Replace `<amount>` with the number of items you want to duplicate.

**Example:**
```text
/dupe 64
```

This attempts to duplicate 64 of the item you're holding.

## Requirements

- Minecraft Java Edition 1.21.11
- Fabric Loader
- Required Fabric API version

## Installation

1. Install Fabric Loader for Minecraft 1.21.11.
2. Install the required Fabric API version.
3. Download the OhDupe `.jar` file.
4. Place it in your Minecraft `mods` folder.
5. Launch Minecraft using your Fabric profile.

## Version

Use this mod only in single-player worlds or multiplayer servers where item duplication is permitted.
