# OhDupe

A Minecraft Java Edition mod featuring a searchable item GUI, configurable item amounts, and a hidden Easter egg.

## Features

- **Item GUI:** Browse and search available Minecraft items.
- **Item Duplication:** Select items and choose the amount.
- **Quick Command:** Use `/ohdupe` to open the GUI.
- **Dupe Command:** Use `/dupe <amount>` to duplicate the item you're holding.
- **Hidden Easter Egg:** Discover a small secret inside the GUI.
- **Dark Turquoise Theme:** A clean, modern interface.

## Requirements

- Minecraft Java Edition **1.21.11**
- Fabric Loader
- Required Fabric API version for the release

## Installation

1. Install Fabric Loader for Minecraft 1.21.11.
2. Install the required Fabric API version.
3. Download the OhDupe `.jar` file.
4. Place the `.jar` file in your Minecraft `mods` folder.
5. Launch Minecraft using your Fabric profile.

## Commands

| Command | Description |
|---|---|
| `/ohdupe` | Opens the OhDupe GUI. |
| `/dupe <amount>` | Duplicates the held item in the specified amount. |

## Compatibility

OhDupe is designed for Minecraft Java Edition 1.21.11 with Fabric. Multiplayer functionality depends on the installed version and server setup.
