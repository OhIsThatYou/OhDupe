# OhDupe

A simple server-side item duplication mod for Minecraft Java Edition.

> **Status:** Early Alpha — v0.1.0-alpha

## Features

- Adds the `/dupe <amount>` command.
- Duplicates the item held in your main hand.
- Simple command-based interface.
- Designed for Minecraft Java Edition 1.21.11 with Fabric.

## Requirements

- Minecraft Java Edition 1.21.11
- Fabric Loader
- Fabric API

## Usage

1. Install Fabric Loader and Fabric API.
2. Place the OhDupe mod JAR in your Minecraft server's `mods` folder.
3. Hold the item you want to duplicate.
4. Run the command:

```text
/dupe 16
```

Replace `16` with the desired amount, from 1 to 64.

**Note:** You need the appropriate permission to use commands on your server. Item stack limits apply, so some items cannot be stacked in large quantities.

## Installation

Download the mod JAR from the project's Releases section when a release is available, then place it in the server's `mods` folder.

## Compatibility

- **Minecraft:** Java Edition 1.21.11
- **Mod loader:** Fabric
- **Environment:** Server-side
